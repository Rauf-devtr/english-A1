# 📚 A1 İngilizce Kelime Öğrenme Uygulaması

A1 seviyesindeki Temel İngilizce kelimeleri öğrenmek, test etmek ve pekiştirmek için tasarlanmış web tabanlı interaktif çalışma uygulaması.

[![Live Demo](https://img.shields.io/badge/Canlı_Uygulama-GitHub_Pages-brightgreen?style=for-the-badge&logo=github)](https://Rauf-devtr.github.io/english-A1/)

---

## 🚀 Özellikler

* **📖 Kelimelere Çalış:** Tüm kelime listesini İngilizce - Türkçe olarak arama filtresiyle inceleyin.
* **✎ İngilizce → Türkçe Test:** Rastgele sıralanan kelimelerle kendinizi sınayın ve skorunuzu görün.
* **↻ Türkçe → İngilizce Tekrar:** Doğru cevabı verene kadar aynı kelimeyi tekrar ettiren pekiştirme modu.
* **📱 Responsive & Hızlı:** Kurulum veya bağımlılık gerektirmeyen, mobil uyumlu saf HTML, CSS ve JS yapısı.

---

## 🛠️ Teknolojiler

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Çalışma Ortamı:** Herhangi bir modern web tarayıcısı
